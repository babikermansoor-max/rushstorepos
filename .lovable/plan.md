# صلاحية جديدة: مدير مخزن (تقارير فقط)

## المطلوب
إضافة صلاحية "مدير مخزن" جديدة بجانب (مالك / مدير / كاشير). الموظف بهذه الصلاحية يشوف صفحتين فقط: **التقارير** و**تقرير المخزن**، ومقيّد بفرعه فقط مثل المدير.

## التغييرات

### 1. قاعدة البيانات
- إضافة القيمة `warehouse` إلى نوع الأدوار `app_role`.
- لا تغيير في سياسات RLS: دوال `can_access_branch` و`current_branch` تسمح أصلاً لأي موظف معتمد بقراءة بيانات فرعه، وهذا يكفي لقراءة المبيعات والمنتجات والمخزون في التقارير. مدير المخزن لن يملك أي صلاحية كتابة (لا إضافة منتجات ولا تعديل مخزون) لأنها مشروطة بـ `is_admin`.

### 2. الواجهة
- `src/hooks/useSession.ts`: إضافة `warehouse` لنوع `AppRole` مع كشف `isWarehouse`.
- `src/lib/format.ts`: تسمية الدور "مدير مخزن".
- `src/components/AppLayout.tsx`:
  - حارس جديد `RequireReports` يسمح للمالك والمدير ومدير المخزن.
  - القائمة الجانبية: مدير المخزن يشوف فقط "التقارير" و"تقرير المخزن".
- `src/routes/_authenticated/reports.tsx` و`stock-report.tsx`: استبدال `RequireAdmin` بالحارس الجديد.
- `src/routes/_authenticated/users.tsx`: إضافة "مدير مخزن" لقائمة اختيار الصلاحية (للمالك).
- `src/routes/index.tsx`: مدير المخزن يتحول بعد تسجيل الدخول إلى صفحة التقارير.
- في التقارير وتقرير المخزن: مدير المخزن مثبّت على فرعه (محدد الفروع مخفي عنه مثل المدير).

### 3. التحقق
- فحص الأنواع والبناء.
- تجربة بحساب مدير مخزن: يدخل على التقارير وتقرير المخزن لفرعه فقط، وأي صفحة أخرى تظهر "لا تملك صلاحية الوصول".

## ملاحظات تقنية
- `ALTER TYPE app_role ADD VALUE 'warehouse'` — إضافة قيمة enum غير كاسرة.
- مدير المخزن قراءة فقط: لا يمر بأي سياسة INSERT/UPDATE لأنها كلها مشروطة بـ `is_admin` (مالك/مدير).
