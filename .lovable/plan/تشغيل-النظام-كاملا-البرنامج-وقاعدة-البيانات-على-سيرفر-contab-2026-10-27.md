# تشغيل النظام كاملاً (البرنامج وقاعدة البيانات) على سيرفر Contabo

## الفكرة
النظام يعتمد على تسجيل الدخول والصلاحيات وقواعد حماية الفروع والعمليات الذرية داخل قاعدة البيانات. أسلم طريقة لنقله بدون إعادة كتابة: نثبت على Contabo **نفس نوع الخادم المستخدم الآن** (نسخة مستضافة ذاتياً بـ Docker)، فيفضل كل شيء شغال كما هو: الدخول، والصلاحيات، والبيع الذري، وسجل العمليات.

عدة كاشيرين في نفس الوقت: مدعوم. كل بيعة تمر بعملية واحدة في قاعدة البيانات تقفل صف المنتج أثناء خصم الكمية، فما في قطعة تتباع مرتين.

## التعديلات والملفات
1. **package.json**
   - `"build:node": "NITRO_PRESET=node-server vite build"`
   - `"start": "node .output/server/index.mjs"`
2. **ملف قاعدة بيانات كامل** `deploy/schema.sql`: يجمع كل الهجرات (الجداول، الأدوار، قواعد الحماية، الدوال مثل البيع والاستبدال وتقييد الدخول وسجل العمليات).
3. **نقل كل البيانات الموجودة** `deploy/import-data.md` + سكربت استيراد:
   - التصدير من Lovable: More ← Database ← Manage ← Settings ← Export data.
   - يشمل: الفروع، المنتجات والأصناف والمخزون، الهواتف، كل الفواتير والمرتجعات والمنصرفات والإصلاحات، سعر الصرف، سجل العمليات، الموظفين وصلاحياتهم.
   - حسابات الموظفين تنتقل بنفس كلمات المرور (منقولة مشفرة كما هي)، فما يحتاج أي موظف يسجل من جديد.
   - ترقيم الفواتير يكمل من آخر رقم.
   - بعد الاستيراد: سكربت يقارن عدد السجلات بين القديم والجديد للتأكد إن ما ضاع شيء.
4. **إعداد Docker** `deploy/docker-compose.yml` + `.env.example`: قاعدة البيانات وخدمة الدخول والواجهة البرمجية والبرنامج نفسه وNginx.
5. **دليل عربي** `DEPLOY_CONTABO.md` خطوة بخطوة:
   - مواصفات السيرفر المقترحة (4 أنوية، 8GB رام على الأقل).
   - تثبيت Docker، تشغيل الخدمات، توليد المفاتيح السرية.
   - استيراد قاعدة البيانات والبيانات.
   - بناء البرنامج وربطه بقاعدة البيانات الجديدة، وربط rushstorepos.com مع SSL.
   - نسخ احتياطي يومي تلقائي لقاعدة البيانات.
6. **مراجعة التزامن**: التأكد إن البيع والمرتجعات وبيع الهواتف كلها تقفل صف المخزون، وإضافة القفل لو ناقص.
7. **التحديث التلقائي عبر GitHub** `.github/workflows/deploy-contabo.yml`:
   - إنت تربط المشروع بـ GitHub من زر GitHub في المحرر (مرة واحدة)، وكل تعديل هنا يتزامن مع GitHub تلقائياً.
   - عند كل تعديل جديد، GitHub يدخل على سيرفر Contabo ويسحب الكود ويبنيه ويعيد تشغيله.
   - تعديلات قاعدة البيانات الجديدة تتطبق تلقائياً على قاعدة سيرفرك في نفس الخطوة.
   - تحتاج تضيف في إعدادات GitHub: عنوان السيرفر ومفتاح الدخول له ورابط قاعدة البيانات (الشرح في الدليل).

## تنبيهات مهمة
- المعاينة هنا في Lovable بتفضل تعرض بيانات Lovable Cloud القديمة، مش بيانات سيرفرك. تعديلات الكود والجداول بتوصل سيرفرك عبر GitHub، لكن البيانات الحقيقية تكون في Contabo بس.
- الصيانة والنسخ الاحتياطي والأمان والتحديثات بتبقى مسؤوليتك.
- النقل نفسه (تشغيل الأوامر على السيرفر) بتعمله إنت أو فني، وأنا بجهّز كل الملفات والدليل. ما بقدر أدخل على سيرفر Contabo.
- خلال النقل لازم توقف البيع فترة قصيرة عشان ما تضيع فواتير.
